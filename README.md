# SAAR-Fleet
SAAR-Fleet is a fully autonomous solar agri-rover built on dual ESP32-S3s &amp; LoRa. Navigating via GPS and 360° 2D ToF LiDARs, it conducts live soil diagnostics using an industrial 7-in-1 RS485 probe (NPK, pH, Moisture). It then deploys dual peristaltic pumps to micro-dose liquid nutrients and water directly to the crop roots.
